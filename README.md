## Overview

iRacing Stats Dashboard aggregates a member's iRacing API data into a comprehensive performance dashboard covering iRating and Safety Rating history, incident rate trends, series participation, lap time comparisons against class field averages, and car-specific performance breakdowns to help racers identify improvement areas.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **iRacing Stats Dashboard** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **iRating History** | Time-series chart of iRating changes across all completed races |
| **Safety Rating** | SR history with incident type breakdown per session |
| **Lap Analysis** | Personal lap times vs field average by car, track, and session |
| **Series Breakdown** | Participation and performance metrics per iRacing series |
